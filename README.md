# 3-1 風力與風向｜學習心智圖拖拉挑戰

翰林版三年級自然・第三單元「風與空氣」3-1 風力與風向的複習網頁，適合在 iPad Safari 上使用。這是靜態網頁，只有一個 `index.html`，不需要伺服器或資料庫。

## 內容

共 12 頁：封面、心智圖骨架，接著 9 頁分支練習，最後是總整理心智圖。

- ① 判斷風的強弱
- ② 風從哪裡來？（方位、指北針構造與使用方法）
- ③ 判斷風向（八個方位、鯉魚旗與風向）
- ④ 自製風力風向計（裝置原理、無風／弱風／強風）
- ⑤ 風的遊戲（紙飛機：順風、逆風、側風）
- ⑥ 充電站：上風處與下風處

## 玩法

- 按住黃色詞卡，拖到虛線框裡；也可以先點詞卡，再點虛線框。
- 放對會變綠色並打勾；放錯會彈回詞卡區。有些詞卡是陷阱卡。
- 「💡 提示」會閃亮一組正確答案，但會扣星星；「🔄 重來」會重新打亂這一頁的詞卡。
- 每頁完成後依錯誤次數得到 1～3 顆星。星星和目前頁數只保存在該裝置的瀏覽器（localStorage）。

## 檔案

- `index.html`：主程式，所有內容都在這個檔案裡。
- `sw.js`：用來清除舊版「生字聽寫輪盤」留在裝置上的離線快取，清完會自動解除註冊。
