# 科學小勇士｜三年級自然（翰林版）闖關島

這是一個複習國小三年級自然（翰林版）的闖關網頁，適合在 iPad Safari 上使用。整個遊戲是一個靜態的 `index.html`，不需要伺服器或資料庫。

## 目前內容

- **第三課　風與空氣**
  - 3-1 風力與風向：心智圖骨架、9 頁分支練習、總整理
  - 3-2 奇妙的空氣：心智圖骨架、9 頁分支練習、總整理
  - 3-3 空氣、風與生活：心智圖骨架、6 頁分支練習、總整理（風改變環境、空氣與風的應用、風向袋、蒲福風級）
  - 單元魔王：複習完一個單元的全部心智圖關卡，就能挑戰那個單元的魔王：風之獸（3-1，22 題）、空氣怪（3-2，22 題）、颶風魔（3-3，24 題）
  - 最後的大魔王「風雲大魔王」（總複習）：3-1～3-3 的心智圖全部完成、三隻單元魔王也都打敗後才會出現。每個單元各出 10 題，共 30 題，答錯過的題目優先出；小勇士有 8 顆愛心
- **第四課　奇妙的溶解**
  - 4-1 分辨物質的方法：心智圖骨架、5 頁分支練習、總整理（顆粒狀的物質、用眼睛看、放大鏡的使用、用鼻子聞與用手摸、觀察要注意安全）
  - 4-2 物質在水中溶解了、4-3 溶解的應用：即將開放
  - 單元魔王：晶晶怪（4-1，20 題）
  - 最後的大魔王「溶解大魔王」（總複習）：4-1～4-3 全部完成、單元魔王都打敗後才會出現

## 玩法

- **心智圖關卡：** 按住黃色詞卡，拖到虛線框裡；也可以先點詞卡，再點虛線框。放對會變綠色，放錯會彈回去。每頁依錯誤次數得到 1～3 顆星。
- **魔王 RPG：** 單元魔王戰有 6 顆愛心，總複習有 8 顆。答對就攻擊大魔王；答錯會被反擊、少一顆愛心，答錯的題目稍後會再出現。全部答對就能打敗大魔王。

## 家長後台

從首頁的「🔒 家長後台」進入，需要先回答一題乘法驗證。

- 可以看到各單元的完成關數、星星數，以及大魔王的挑戰紀錄。
- 錯題紀錄會列出心智圖拖錯、大魔王答錯的題目，包括正確答案、孩子選了什麼、錯了幾次，可以依單元或來源篩選。
- 錯題可以匯出 CSV，也可以清除紀錄。
- 有「提前開放所有魔王」的測試開關。

所有紀錄只保存在該裝置的瀏覽器（localStorage）。換裝置或清除 Safari 網站資料，紀錄就會消失。

## 檔案

- `index.html`：主程式，所有內容都在這個檔案裡。
- `sw.js`：清除舊版「生字聽寫輪盤」留下的離線快取，清完會自動解除註冊。

## 新增單元

在 `index.html` 的 `LESSONS` 資料中加入單元，需要準備：

- `pages`：心智圖頁面
- `questions`：大魔王題庫
- `monster`：大魔王角色

把 `coming: true` 拿掉，單元就會開放。在課程上設定 `final`，就會有那一課的總複習大魔王；新增的單元會自動列入它的解鎖條件和出題範圍。

## 部署

GitHub Pages：Settings → Pages → Deploy from a branch → `main` / `(root)`。
